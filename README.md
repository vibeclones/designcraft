# designcraft (Vibeclones mirror)

Hosted copies of the browser (WebAssembly) builds of [designcraft](https://github.com/storytold/designcraft), a InDesign-style layout editor by ArtCraft. This repo only mirrors upstream release zips; the code is theirs.

- Latest: `/designcraft/latest/`
- Specific version: `/designcraft/v<version>/`
- Version list: `/designcraft/versions.json`

Each version folder is the unmodified contents of upstream's `designcraft-web-<version>.zip` release asset, including its license files. Upstream license: . A scheduled workflow mirrors new releases.
